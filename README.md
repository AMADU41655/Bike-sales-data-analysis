# Bike-sales-data-analysis


## Project Overview

This project presents an Excel-based analysis of bike sales data. The analysis explores sales performance, customer patterns, product trends, and key business insights that can support better decision-making.

## Objectives

- Analyze bike sales performance.
- Identify customer and product trends.
- Summarize key insights using Excel tools.
- Present findings in a clear and professional dashboard format.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Charts
- Data Cleaning
- Dashboard Design

## Project File

- `BIKE SALES DATA ANALYSIS.xlsx`

## Key Insights

Add your main findings here, for example:

- Best-performing customer segments

- Sales trends by region, gender, age group, or income level
- Important patterns from the dashboard

## How to Use This Project

1. Download the Excel file.
2. Open it using Microsoft Excel.
3. Review the cleaned data, pivot tables, charts, and dashboard.
4. Use the dashboard to understand the main sales insights.
